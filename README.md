## Weaver

Weaver is a modern, minimalist weather application designed for a sleek and informative forecasting experience. Developed with SvelteKit, TypeScript, and Chart.js, the platform provides real-time weather data, interactive hourly trends, and a comprehensive daily forecast through a highly polished, responsive interface.

## Features

- **Real-time Weather:** Accurate current conditions fetched directly from the Open-Meteo API.
- **Interactive Hourly Chart:** Visualize temperature trends for the next 24 hours with a custom-styled Chart.js implementation.
- **Daily Forecast:** Structured 6-day outlook with detailed weather descriptions and temperature ranges.
- **Global Location Search:** Dynamic city and country search powered by geocoding services.
- **Responsive Architecture:** Fully optimized interface ensuring a seamless experience across mobile, tablet, and desktop environments.
- **Glassmorphism Design:** Modern aesthetic with backdrop blurs and subtle borders for a premium look.
- **Type Safety:** Robust and maintainable codebase ensured through strict TypeScript implementation.
- **High Performance:** Lightweight and fast delivery powered by Vite and SvelteKit's efficient runtime.

## Tech Stack

- **SvelteKit**: A framework for building high-performance web applications.
- **TypeScript**: A strongly typed programming language that builds on JavaScript.
- **Chart.js**: Flexible JavaScript charting for data visualization.
- **Open-Meteo API**: Free and open-source weather API.
- **Lucide Svelte**: Clean and consistent icon library for modern UIs.

## Getting Started

Follow these instructions to set up a local development environment.

### Prerequisites

- **Node.js** and **NPM**.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/fahmirizalbudi/weaver.git
   cd weaver
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Start the development server:**

   ```bash
   npm run dev
   ```

## Usage

### Execution Commands

- **Development:** `npm run dev`
- **Build:** `npm run build`
- **Preview:** `npm run preview`

The application will be accessible at [http://localhost:5173](http://localhost:5173).
